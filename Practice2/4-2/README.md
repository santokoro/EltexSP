# Очередь с приоритетами (Задание 4.2)

## Описание

Реализация очереди с приоритетами на языке C.  
Приоритет задается целым числом от **0 до 255** (0 — низший, 255 — высший).

### Возможности

- Добавление элемента с указанным приоритетом
- Извлечение элемента с **максимальным** приоритетом
- Извлечение элемента с **указанным** приоритетом
- Извлечение элемента с приоритетом **не ниже** заданного
